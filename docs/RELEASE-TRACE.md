# ردیابی انتشار نسخه‌ها

این فایل برای جلوگیری از اختلاف میان کد محلی، GitHub و GitHub Pages نگهداری می‌شود.

## قرارداد انتشار

هر تغییر قابل استفاده پس از اجرای `pnpm check`، `pnpm build` و `git diff --check` روی شاخهٔ `main` commit و push می‌شود. سپس workflow با عنوان `Deploy to GitHub Pages` باید برای همان SHA موفق شود. پس از موفقیت workflow، bundle نشانی عمومی با `curl` بررسی می‌شود و متن/ویژگی اصلی تغییر باید در asset منتشرشده وجود داشته باشد.

## آخرین تغییر قابل مشاهده

- **ویژگی:** کلیدهای سریع انتخاب نوع عملیات در فرم ثبت عملیات؛ شامل انتقال، خرید کالا، فروش کالا، خرید شریک، دریافت شریک، مساعده و تسویه شریک.
- **Commit:** در زمان انتشار این سند تولید می‌شود.
- **URL عمومی:** https://rasool083.github.io/accounting-workshop-pwa/
- **مسیر کاربر:** عملیات مالی → ثبت عملیات
- **آزمون منبع:** `pnpm check`, `pnpm build`, `git diff --check`
- **آزمون bundle:** جست‌وجوی عبارت‌های «خرید کالا»، «فروش کالا» و «حساب پرداخت» در asset خروجی Pages.

## تمایز نسخهٔ محلی و عمومی

LocalStorage و داده‌های کاربر روی هر مرورگر مستقل هستند و با انتشار کد حذف یا همگام نمی‌شوند. بنابراین مشاهدهٔ داده‌های جدید نیازمند backup/restore جداگانه است؛ اما مشاهدهٔ گزینه‌ها و ساختار رابط باید پس از انتشار و بارگذاری مجدد URL عمومی انجام شود. برای رفع cache، تب قدیمی بسته و URL اصلی دوباره باز شود.
